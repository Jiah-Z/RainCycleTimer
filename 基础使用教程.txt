雨循环计时器 - 使用教程


一、启动程序

在Python环境下运行main.py（或使用.bat文件打开）
程序启动后不会显示任何窗口，只在右下角系统托盘区域出现一个图标。


二、显示/隐藏时钟

方法一：按键盘 Ctrl + Shift + F（默认显示热键）
方法二：左键单击右下角的托盘图标

再次操作即可隐藏时钟。


三、设置倒计时

1. 右键点击右下角托盘图标
2. 选择 "Set Countdown (seconds)..."
3. 输入秒数（例如 300 代表 5 分钟）
4. 点击确定，时钟立刻开始倒计时


四、调整业力等级（中间图标）

1. 右键点击右下角托盘图标
2. 选择 "Set Karma Level (1-10)..."
3. 输入 1 到 10 的数字
4. 点击确定，业力图标立即改变


五、加载自定义配置

1. 右键点击右下角托盘图标
2. 选择 "Load JSON..."
3. 选择你的 .json 配置文件
4. 时钟自动切换至新配置

（JSON 文件可自定义圆点数量、总时长、业力等级等，还可进行自定义多段计时等相对高级的功能）
！！可使用配套的RainCycleTimerEditor来更方便地写配置文件！！


六、右键菜单其他功能

- Zoom：放大/缩小/重置时钟大小
- Settings：
  - Set Show Hotkey：修改显示热键
  - Set Quit Hotkey：修改退出热键
  - Sound ON/OFF：开关声音
- Toggle Always on Top：窗口置顶开关
- Quit：退出程序


七、退出程序

方法一：右键托盘图标 → Quit
方法二：按 Ctrl + Shift + Q（默认退出热键）


八、移动时钟位置

鼠标左键按住时钟圆圈，拖拽到任意位置即可。


常见问题

Q：为什么启动后桌面上什么都没有？
A：程序默认是隐藏的，请按 Ctrl+Shift+F 显示时钟。

Q：热键没反应怎么办？
A：请以管理员身份运行程序。右键点击 exe 文件 → "以管理员身份运行"。

Q：如何更改热键？
A：右键托盘图标 → Settings → Set Show Hotkey，输入新组合键即可。

Q：倒计时结束后会发生什么？
A：会播放音效，时钟会显示一次"波"扩散动画，然后进入空闲状态。

Q：如何让时钟开机自启？
A：将 RainCycleTimer.exe 快捷方式放入 Windows 启动文件夹即可。
